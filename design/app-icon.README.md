# Иконка приложения — КАНОННЫЕ ФАЙЛЫ, не сборка

`app-icon-1024.png` и `../public/apple-touch-icon.png` (он же
`app-icon-180.png`) — **файлы из проекта Claude Design**
«AOCG AI Office Design System», каталог `assets/`. Получены 28.08.2026.

**Не пересобирать.** `scripts/build-app-icon.py` остаётся в репозитории,
но его роль сменилась: он больше не источник, а ПРОВЕРКА — собирает
иконку из спецификации и сверяет с канонным файлом. Разошлись — значит
спецификацию в ДС поменяли, а файл сюда не подтянули.

## Спецификация, подтверждена ДС 28.08.2026

`preview/brand-appicon.html` в проекте ДС:
«Иконка приложения — только вишнёвая #A4161A. Белая „Λ“ на вишнёвом поле,
скруг. 22% (iOS superellipse)». Три вопроса подтверждены дословно:
глиф ровно 50% стороны — да; поле сплошное #A4161A без градиента и тени —
да; подпись под иконкой «AI Офис» — да.

## ⚠️ Прямые углы — это НЕ расхождение со «скруг. 22%»

22% рисует сама iOS: она накладывает маску-суперэллипс на
`apple-touch-icon`, её радиус ~22.4%. Полноразмерный квадрат ДАЁТ канонный
вид. Своё скругление добавило бы прозрачные углы, которые iOS заливает
чёрным. Трактовка подтверждена ДС тем же ответом.

## Замер при подмене 28.08.2026

Моя сборка отличалась от канона на один пиксель: глиф 89 px против 90,
поля 46/45 против 45/45, режим RGB против RGBA (альфа 255…255, то есть
полностью непрозрачна — чёрных углов не даст). Один пиксель неважен сам
по себе, но «почти совпало» — плохое состояние: либо файл канонный, либо
собран нами, смешивать нельзя. Поставлен канонный.
